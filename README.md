# house-price-detector

This is a simple machine learning web application built with Python and Streamlit. It uses a Linear Regression model to predict the estimated price of a house (in Lakhs) based on its area in square feet.

## Features
- Interactive web UI using Streamlit
- Simple Linear Regression model using scikit-learn
- Slider input for house area (sq ft)
